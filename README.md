# Credit-Risk-Portfolio-Monitoring
Credit Risk Portfolio Monitoring & Oversight Analytics

Project Overview

A credit risk analytics project demonstrating portfolio monitoring, delinquency analysis, exception identification, and predictive model evaluation using Python, SQL, statistics, and machine learning.

Dataset

Source: UCI – Default of Credit Card Clients

30,000 customer records

Historical Taiwanese credit-card data (2005)

Six months of repayment, billing, and payment history

Target: Default payment next month

Tools

Python | Pandas | NumPy | SQL (SQLite) | Scikit-learn | Matplotlib | Seaborn

Key Findings

Overall default rate: 22.12%

Customers with 2+ months' delay: 10.43%

Default rate in the 2+ months' delay group: 69.55%

Flagged portfolio default rate: 38.27%, compared with 16.06% for non-flagged customers.

Best model ROC-AUC: 0.728

Model recall in the 200K+ credit-limit segment: 28.8%

Work Completed

Data cleaning and exploratory analysis

Credit utilisation and delinquency segmentation

Portfolio monitoring and illustrative KRIs

SQL-based risk analysis

Exception monitoring and customer prioritisation

Statistical hypothesis testing

Logistic regression and model evaluation

Segment-level model validation

Oversight findings and recommendations

Limitations

Historical data from Taiwan (2005), not current or AMEX-specific.

KRI thresholds and exception rules are illustrative.

Model requires further validation before operational use.

Findings indicate associations, not causation.
